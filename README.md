# KoraHome

App compagnon de famille : listes partagées, tâches de la maison, agenda, repas, budget et infos de la maison. Prototype PWA pour iPhone.

```sh
npm install
npm run dev     # puis ouvrir l'adresse affichée dans Safari
npm test
npm run build
```

Installer sur iPhone : ouvrir https://kora-cassa.netlify.app dans Safari, puis « Sur l'écran d'accueil » (voir `docs/en-ligne.md`). Depuis le Mac de la maison : `npm run serveur`, puis voir `docs/installer-sur-iphone.md`.

Voir `CLAUDE.md` pour l'architecture.
