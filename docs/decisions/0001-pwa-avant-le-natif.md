# 0001 — Une application web installable d'abord, le natif plus tard

**Décidé** le 7 octobre 2026, par Melo.

**Choix** : Kora est une PWA (React, TypeScript, Vite) installée sur l'écran d'accueil de l'iPhone.

**Pourquoi** : pas encore de compte développeur Apple ; une PWA se publie en une fusion et se met à
jour seule ; la couche de règles pure (0002) se reprendra telle quelle en Swift.

**Ce que ça coûte** : pas de widgets d'écran d'accueil, pas de Live Activities, pas de rappels au
lieu, des notifications plus fragiles. Le plan du natif (coque autour de l'app web, pas avant le
printemps 2027) attend une décision de Melo.
