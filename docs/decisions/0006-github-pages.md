# 0006 — Publier sur GitHub Pages

**Décidé** le 20 octobre 2026, après l'épuisement des crédits Netlify.

**Choix** : chaque fusion dans `main` publie sur https://dmeloz.github.io/korahome/ (action `Pages`).
Le dépôt est public pour cela.

**Pourquoi** : gratuit, sans compteur, publié par la même action que les vérifications.

**Ce que ça coûte** : pas d'en-têtes de sécurité à soi ; l'adresse est partagée avec toute autre page
du compte. Un domaine à soi réglerait les deux.
